# TDLAS 测氢系统 V3.2.2

**一套用于氢气光谱实验的 Windows 桌面上位机软件，将信号采集、光谱处理、实时图表、相机观察和实验数据保存集中在同一个程序中。**

TDLAS 是“可调谐半导体激光吸收光谱”的简称。本程序用于配合相关测量装置进行实验观察、光谱分析和数据记录，也提供无需连接测量硬件的模拟演示模式。

当前版本已实现电压采集接入、吸光度与 Voigt 拟合、峰值趋势、摄像预览及媒体保存。**氢气浓度尚未完成标定，浓度栏保持未校准/空值；现阶段不能把程序输出当作已标定的氢浓度或测量精度证明。**

版本：**V3.2.2**。本文根据 2026-11-12 的正式源码与现有交付文件编写。

## 这个程序能做什么

| 功能 | 具体用途 |
| --- | --- |
| 测量采集 | 发现并选择 NI 采集设备，配置 AI 电压采集；同时提供模拟采集 |
| 参数配置 | 设置采样率、块点数、输入通道及量程；支持可选 AO 波形参数、校验与参数恢复 |
| 光谱处理 | 对连续完整扫描周期进行平均，处理基线、计算吸光度并进行 Voigt 拟合 |
| 实时结果 | 展示峰值吸光度、光强百分比、FV 光谱和峰值趋势 |
| 调试观察 | 管理员可查看原始采集电压、平均/处理波形和拟合结果 |
| 峰值数据 | 管理员可查看峰值历史、筛选和明细，并开启/停止 CSV 连续记录 |
| 摄像观察 | 选择系统/UVC 相机、实时预览、设备方向/缩放控制、预览旋转 |
| 拍照与录像 | 将实验中的相机画面保存为 PNG 图片或 MJPEG 视频 |
| 数据记录 | 自动保存完整实验资料，并可选择额外的 TXT、CSV 与摄像媒体保存目录 |
| 实验追溯 | 为实验关联运行 ID、参数快照、数据、结果、时间与设备来源 |
| 模拟演示 | 使用模拟采集和模拟相机观察完整软件流程 |

程序适合实验调试、测量过程观察、光谱结果分析和数据留存。真实氢气测量还需要相应光路、采集设备、驱动、现场配置和标定资料，软件本身不能替代这些条件。

本版重点修正相机方向和缩放控制，让按钮直接控制所选相机提供的 PTZ 能力：

- 提供“相机人工复验”入口，使用真实系统相机、模拟测量采集，便于独立检查取景控制。

## 运行条件

- Windows 10/11，64 位。
- 解压到具有读写权限、空间充足的本地目录。
- 发布包已经附带 Qt、MSVC 和多媒体相关运行库。普通使用者不需要安装 Qt SDK、Visual Studio、CMake 或 Python。
- 连接真实 NI 采集设备时，目标电脑需要安装适用的 NI-DAQmx 驱动，并配置好设备和通道。
- 连接真实相机时，需要 Windows/UVC 或厂商驱动，并允许桌面应用访问摄像头。

请整体保留发布目录中的 DLL、插件文件夹、配置和启动脚本。**只复制 `tdlas_hydrogen_ui.exe` 无法组成完整运行环境。**

## 一次实验怎么操作

1. **启动并登录。** 初次了解程序可使用模拟模式。
2. **核对设备。** 在设置菜单刷新设备识别，选择本次采集设备；需要摄像时，在摄像界面明确选择相机。
3. **检查参数。** 在参数区确认采样率、点数、通道及波形等设置，保存/提交参数并确认校验反馈。软件示例值不等于现场硬件批准参数。
4. **选择附加保存目录。** 如需 TXT、CSV 或摄像文件，先点击侧栏“数据保存”，选择本次使用的目录。
5. **点击“开始采集”。** 程序创建实验记录并显示原始/处理结果。完整光谱需要等待连续 20 个完整周期，不会每来一个采集块就产生一组拟合结果。
6. **观察图表和相机。** 查看峰值、FV 和光强；管理员可切到调试页或峰值页。需要时拍照、录像或开启 CSV 连续记录。
7. **结束实验。** 先停止 CSV 连续记录和录像，再点击“停止采集”，等待程序完成写入与停止。发生故障时查看提示，排除原因后再复位。

建议每次实验单独确认保存目录；完整归档位置与侧栏附加保存目录的关系见下文。关闭前完成正常停止，避免使用强制结束进程代替停止操作。

## 图表和结果怎么看

| 显示内容 | 含义 |
| --- | --- |
| 原始电压 | 采集设备输入电压，纵轴 V、横轴 s；可以先于拟合结果更新 |
| 平均/处理与拟合电压 | 完整周期组平均及对应拟合，用于观察光谱处理效果 |
| FV 曲线 | 相对频率与拟合吸光度；频率轴 cm⁻¹，吸光度无量纲 |
| 峰值吸光度 | 当前处理结果提取的吸光度峰值 |
| 峰值趋势 | 峰值随采集时间变化的记录，界面按电脑本地时间显示 |
| 光强百分比 | 当前算法计算的光强指标，不表示氢气浓度 |
| 气体浓度 | 当前未标定，显示未校准或空值 |

“等待数据”“模拟”“未校准”和错误提示都属于结果含义的一部分。不要把空值理解为浓度为零，也不要把尚未形成完整周期组理解为采集一定失败。

## 相机功能说明

### 预览与取景

选择相机后，可在主页面和摄像界面查看预览；两处共享取景/旋转状态。

- 方向/缩放是相机设备能力，是否可用取决于驱动。
- Zoom 显示驱动原始数值，不是倍率。按钮禁用可能表示到达边界，也可能是设备不支持。
- 设备 PTZ 可能由电子取景实现，仅凭按钮和画面变化无法认定机械云台或光学变焦。
- 顺时针 90° 只改变预览显示方向，连续四次回到原方向。
- 相机控制“复位”恢复驱动默认取景并清除软件旋转，不保证回到本次启动时的取景。

### 拍照和录像

- 拍照/录像需要已开始测量并存在有效实验。
- 照片格式为 **PNG**，录像格式为 **MJPEG（`.mjpeg`）**。
- 保存的是源画面；设备方向和缩放改变会体现在文件中，软件 90° 预览旋转不会写入媒体。
- 切换媒体保存根目录可能结束当前录像，建议在拍摄前选好目录。
- 摄像界面的“图像/视频管理”可打开媒体目录；这不等于具有完整的媒体数据库或视频转码系统。

### 单独检查真实相机

在发布目录双击 `相机人工复验.cmd`，登录后进入摄像界面选择实际相机。此入口将采集设为模拟，不自动开始测量；不开始测量也可以检查预览和方向/缩放/旋转。

更完整的检查步骤见源码中的 `docs/CAMERA_MANUAL_REVIEW.md`。已验证设备名称 `4K ZOOM CAMERA` 只是本次测试设备，不是唯一可选设备名单。

## 数据保存在哪里

程序同时存在“完整实验归档”和“操作员选择的附加保存目录”。两者用途不同，建议一起备份。

### 1. 完整实验自动归档

便携默认配置把完整实验保存在运行目录的 `data` 下，按 UTC 日期和实验 ID 分目录：

```text
运行目录\data\年\月\日\实验ID\
  manifest.json          实验清单、状态和计数
  parameters\            本次参数快照
  raw\                   原始电压 CSV
  results\               完整处理结果 JSON
  logs\events.jsonl      实验事件
```

系统审计另存于启动归档根的 `system-logs` 下。实际根目录可由配置或环境变量覆盖；日期采用 UTC，因此可能与本地日历日期不同。

自动归档由程序存储服务管理，停止时需要完成队列写入。它保留的数据比现场四列 TXT/CSV 更完整，适合追溯。

### 2. 点击“数据保存”选择的目录

选择目录后，当前代码创建：

```text
您选择的目录\
  CSV数据保存\           管理员峰值页开启的连续 CSV
  算法处理数据\          当前预留目录
  拍照摄像\              PNG、MJPEG 和 index.jsonl
  TXT\算法处理数据.txt   追加的结果摘要
```

TXT 每条记录包含：

```text
[时间戳,峰值吸光度,光强百分比,氢气浓度]
```

时间为带毫秒的本地时间；没有标定时浓度字段留空。TXT 在选目录后随有峰值的结果追加。

管理员峰值页的“导出 CSV”当前作为连续记录开关：点击一次新建文件并记录后续结果，再次点击关闭。当前四列连续 CSV 不是对页面历史筛选结果的一次性完整导出，也不能替代完整实验归档。

**当前实现的注意事项：**

- 侧栏所选目录只在本次程序进程中生效，重启后需重新选择。
- 该操作改变 TXT、CSV 新建目标和摄像媒体位置，**不会迁移或重新配置已经初始化的完整实验归档根目录**；归档仍可能在运行目录的 `data` 下。
- `算法处理数据` 目录的存在不代表完整结果已经写入该目录，完整 JSON 请到自动归档中查找。
- 连续 CSV 的跨次采集序号处理与切换目录时的已打开文件行为仍有实现限制，建议每次采集结束关闭 CSV，下次重新开启；完整记录以实验归档核对。

## 配置与整体搬移

运行目录包含 `portable-config/runtime.ini`：

```ini
[paths]
dataDirectory=data
configurationDirectory=config

[backends]
acquisition=auto
camera=system
```

相对路径根据 EXE 所在目录解析。`config` 中的参数和存储配置在使用时创建/保存；测量参数可跨启动恢复。

搬到其他电脑时，关闭程序后复制完整运行目录。若希望保留实验历史，连同已生成的 `data` 和外部选择的保存目录一起备份。系统级 NI/相机驱动仍需在新电脑安装。

技术人员可以用 `TDLAS_STORAGE_ROOT`、`TDLAS_STORAGE_CONFIG`、`TDLAS_PARAMETER_CONFIG`、`TDLAS_ACQUISITION_BACKEND`、`TDLAS_CAMERA_BACKEND`、`TDLAS_CAMERA_DEVICE_ID` 显式覆盖配置；非空环境变量优先于便携配置，详细语义见 `AGENTS.md`。更换电脑后发现路径或设备来源异常时，检查是否保留了这些覆盖。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 提示缺 DLL 或 Qt 平台插件 | 重新解压完整发布包，从便携启动脚本启动，检查 DLL/插件是否缺失 |
| 不知道先试什么 | 用 `启动便携版.cmd --mock` 演示，登录后开始采集 |
| 找不到 NI 设备 | 检查驱动安装、系统设备状态、后端设置与通道，再刷新设备识别 |
| 无相机画面 | 检查相机连接、Windows 摄像权限、设备选择，以及是否被其他程序占用 |
| 放大或方向按钮灰色 | 查看设备能力和边界；已到 Zoom 上限时先缩小 |
| 拍照/录像不可用 | 确认相机有预览、测量正在运行、实验 ID 有效且目录可写 |
| 浓度一直未校准 | 这是当前版本边界，需要批准的标定模型、数据与单位后才能实现 |
| 开始采集后拟合稍后才出现 | 需要等待完整的 20 周期处理组，原始数据与拟合不是同一刷新节奏 |
| TXT/CSV 找不到 | 检查是否选过“数据保存”目录；CSV 还需在管理员峰值页开启 |
| 重启后保存位置变化 | 侧栏附加目录不跨启动保留，重新选择；检查默认 data 和环境覆盖 |
| 预览转了 90°，照片没转 | 软件旋转仅影响预览，媒体保留源方向 |
| 故障后无法重新开始 | 记录错误提示，停止/排除设备或磁盘原因，再执行测量复位 |
